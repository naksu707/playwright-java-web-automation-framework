# Playwright Java Web Automation Framework
---

###  Description

This repository contains the development of a **web automation framework using Playwright with Java**, created as part of the practical activities of the course:

**“Master Class de Web Automation con Playwright + Java”**

The purpose of this project is to apply and reinforce knowledge acquired throughout the course, including automation architecture, test organization, best practices, and modern web testing approaches.

This repository demonstrates the implementation of concepts such as:

- Web automation with Playwright
- Java-based test development
- Test structure and organization
- Page Object Model (POM)
- Functional and end-to-end (E2E) testing
- Reporting and test execution practices
- Automation framework design

### About this Repository

This project serves as a learning and practice environment where different automation scenarios, framework configurations, and testing strategies are implemented progressively during the course.

The repository may continue evolving as new concepts and improvements are incorporated.

###  Descripción

Este repositorio contiene el desarrollo de un **framework de automatización web utilizando Playwright con Java**, realizado como parte de las actividades prácticas del curso:

**“Master Class de Web Automation con Playwright + Java”**

El propósito de este proyecto es aplicar y reforzar los conocimientos adquiridos a lo largo del curso, incluyendo arquitectura de automatización, organización de pruebas, buenas prácticas y enfoques modernos de testing web.

En este repositorio se implementan conceptos como:

- Automatización web con Playwright
- Desarrollo de pruebas con Java
- Estructuración y organización de pruebas
- Patrón de diseño Page Object Model (POM)
- Pruebas funcionales y end-to-end (E2E)
- Reportería y ejecución de pruebas
- Diseño de frameworks de automatización

###  Acerca de este Repositorio

Este proyecto funciona como un entorno de aprendizaje y práctica donde se implementan progresivamente diferentes escenarios de automatización, configuraciones del framework y estrategias de pruebas vistas durante el curso.

El repositorio puede continuar evolucionando a medida que se incorporen nuevos conceptos y mejoras.
